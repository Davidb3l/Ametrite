# Getting help

- **Questions, "how do I...", "is this expected?"**: open an issue with the
  **Question** template. Search [existing issues](https://github.com/Davidb3l/Ametrite/issues?q=is%3Aissue)
  first; someone may have asked already.
- **Bugs**: use the **Bug report** template.
- **Security vulnerabilities**: do **not** open a public issue. Follow
  [SECURITY.md](SECURITY.md) and report privately through GitHub.
- **Docs**: the [README](README.md) (install, quickstart, command reference),
  [AGENTS.md](AGENTS.md) (the agent work loop and etiquette),
  [ametrite.com](https://ametrite.com), and `amt --help` / `amt <command> --help`
  for every CLI command.
- **The wider suite** (Sirius Forester, Hayvenhurst, Catryna Wikinelli,
  PingMyBell): see [Sothis](https://github.com/Davidb3l/Sothis) and
  [getsothis.com](https://getsothis.com). Questions about how the tools work
  together are welcome here too.

Ametrite is maintained by one person. Expect a reply within a few days.
When you report a problem, include `amt --version`, your OS, how you installed
`amt`, and the output of `amt doctor`.
